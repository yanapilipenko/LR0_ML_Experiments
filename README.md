LR0_intellect_sysstem
Лабораторная работа №0. Интеллектуальные системы.

Описание
Исследование воспроизводимости обучения нейронных сетей и подбор гиперпараметров с использованием PyTorch, Optuna и MLflow.

Структура
configs/ — конфигурации экспериментов
data/ — данные и разбиение
src/ — исходный код
reports/ — отчёты и графики
runs/ — результаты запусков

Используется полносвязная нейронная сеть.

Входной слой принимает 64 признака изображения. Скрытые слои используют функцию активации ReLU. Выходной слой содержит 10 нейронов — по одному для каждого класса цифр.

В качестве функции потерь применяется CrossEntropyLoss, оптимизатор — Adam.
Сохранение результатов

В проекте используются следующие средства хранения результатов:

runs/ — результаты отдельных запусков обучения: конфигурации, метрики, история обучения и предсказания.

optuna.db — результаты подбора гиперпараметров Optuna.

mlflow.db — данные экспериментов и запусков MLflow.

mlruns/ — каталог с артефактами запусков MLflow.

reports/ — итоговые отчёты и графики экспериментов
Установка и запуск

1. Создание виртуального окружения

python -m venv .venv

2. Активация виртуального окружения

.\.venv\Scripts\Activate.ps1

3. Установка библиотек

pip install -r requirements.txt

4. Запуск базового обучения

python train.py --config configs/base.yaml --seed 0

5. Подбор гиперпараметров

python -m src.optimize --config configs/search.yaml

6. Запуск оптимизированной модели

python train.py --config configs/best.yaml --seed 0
Для выполнения оценки на тестовой выборке используется параметр --eval-test.

Для запуска интерфейса MLflow используется команда:

mlflow ui --backend-store-uri sqlite:///mlflow.db

После запуска интерфейс доступен в браузере:

http://127.0.0.1:5000

В интерфейсе можно просматривать эксперименты, параметры запусков, метрики и сохранённые артефакты.
